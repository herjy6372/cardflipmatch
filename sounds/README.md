# Card Flip Match 오디오

배경음은 사용자가 제공한 `bgm/background.mp3`를 그대로 사용한다. FFmpeg 전체 디코딩 검증을 통과했으며 표시 길이는 약 3분 0.43초다. 원본은 수정하지 않았다.

## 직접 제작한 효과음

| 파일 | 합성 원본 길이 | 역할 |
| --- | ---: | --- |
| flip.mp3 | 0.16초 | 카드 오픈, 가벼운 상승음과 짧은 노이즈 |
| match.mp3 | 0.44초 | 짝 일치, 밝은 두 음 |
| mismatch.mp3 | 0.34초 | 불일치, 부드러운 하강음 |
| success.mp3 | 1.12초 | 라운드 성공, 상승 멜로디와 화음 |
| fail.mp3 | 0.84초 | 시간 초과, 짧은 하강 멜로디 |

Python 표준 라이브러리로 파형과 음량 외곽선을 합성했다. 외부 녹음·음악 샘플을 사용하지 않았다. 44.1kHz 모노, MP3 128kbps로 저장했으며 모두 전체 디코딩 검증을 통과했다. MP3 인코딩 패딩에 따라 표시 길이는 조금 달라질 수 있다. 청감과 배경음 혼합 균형은 `../docs/sound-preview.html`에서 확인할 수 있다.

무손실 합성 원본은 `source/*.wav`, 재생성 스크립트는 `generate_sfx.py`다. 스크립트는 기존 파일 덮어쓰기를 거부한다. 효과음 자산 제작까지 완료했으며 실제 게임 이벤트 연결은 아직 하지 않았다.
