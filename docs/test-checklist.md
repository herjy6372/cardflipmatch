# 게임 구현 테스트 결과

검증일: 2026-09-12. 테스트 대상은 루트 `index.html`과 연결된 CSS·JavaScript·로컬 미디어다. 기존 미리보기의 과거 점검과 구분한다.

## 실행 환경과 결과

- [x] Windows 설치형 Chrome: 로컬 파일에서 게임 테스트 13개 그룹 통과.
- [x] Windows 설치형 Chrome: 로컬 HTTP에서 같은 게임 테스트 13개 그룹 통과.
- [x] Windows 설치형 Chrome: 미디어·오류·마지막 짝 경계 검증을 포함한 추가 테스트 9개 그룹 통과(HTTP 전체 게임 재검증 그룹 포함).
- [x] Windows 설치형 Edge: 로컬 파일에서 게임 테스트 13개 그룹 통과.
- [x] 게임 JavaScript 문법 검사 통과. 정상 리소스 연결에서 브라우저 예외·HTTP 리소스 오류 없음.
- [x] 새 반응 PNG 2개는 각각 971×1620 RGBA이며 투명 알파 포함. 기존 배경음 전체 디코딩 재검사 통과, 브라우저 표시 길이도 179~181초 범위 통과.

자동 테스트: `tests/game.test.cjs`, `tests/media.test.cjs`. 결과 JSON과 검토한 화면 이미지는 `.tools/test-results/`에 생성한다. 재실행 시 같은 이름으로 갱신된다. 단위 검사는 게임의 설정·정렬 모듈, 브라우저 검사는 실제 DOM 입력과 화면 전환을 대상으로 한다. 시간 경계·탭 상태·리소스 실패는 테스트에서 시계·이벤트·응답을 제어하여 재현한다.

## 규칙·입력·상태

- [x] 1~50라운드 카드 수·시간, 모든 난이도 경계, 잘못된 라운드 거부.
- [x] 카드 ID 고유, 각 pairId 정확히 두 장, 이모지 수 충족.
- [x] 별명·나이·성별 필수 선택, 공백 별명 거부, 선택 안 함 제공.
- [x] 키보드 Enter 선택, 같은 열린 카드 재선택 무시.
- [x] 불일치 두 장 공개 후 복구, 판정 중 세 번째 선택 무시, 시도 1회 증가.
- [x] 짝당 100점·라운드 성공 보너스를 게임 전체에 누적, 최종 결과 고정·중복 저장 방지.
- [x] 실제 브라우저에서 1~49라운드 성공은 완료 안내만 표시, 결과·순위 비노출 및 기록 0개 유지. 50라운드 성공 후 최초 1개 저장.
- [x] 50라운드 전체 완료 뒤 1라운드 다시 시작. 51라운드로 이동하지 않음.
- [x] 종료 후 새 게임은 1라운드·누적 0점으로 초기화. 다음 라운드에서는 누적 점수 유지.
- [x] 불일치 예약 중 포기 → 새 게임에서 이전 예약이 새 판을 바꾸지 않음.
- [x] 마지막 두 번째 선택 시 남은 시간 1ms는 성공, 0ms는 실패. 점수·기록은 한 번만 확정.
- [x] 새로고침 시 READY, 진행 중인 판·입력 폼 복원 없음.

- [x] 50라운드 각 1.7초 조건에서 총점 107,570점·790쌍·791시도·85초 검증. 완료 안내 대기 시간 제외.
- [x] 2라운드 시간 초과·판정 중 포기: 이전 성공 점수와 현재 찾은 쌍 합산, 실패 보너스 없음.
- [x] 완료 안내에서 포기 시 이미 합산한 라운드 중복 계산 없음, 즉시 포기는 0점 종료.

## 직접 확인이 남은 항목

- [ ] 실제 Android·iPhone 터치 조작과 기기별 이모지 식별성, Safari/WebKit 동작. 현재 모바일 검증은 데스크톱 브라우저의 화면 크기 변경이다.
- [ ] 실제 기기에서 배경음 끝→처음의 청감상 연결, 보컬 유무·음악 분위기, 효과음과의 음량 균형. 자동 재생·디코딩 검사는 청취 품질 검증을 대체하지 않는다.
- [ ] 40~50라운드의 실제 사람 플레이 난이도와 모바일 세로 스크롤 편의성.
- [ ] 사용자 제공 배경음의 구체적인 출처·이용 허가 기록 보완. 기존 파일은 수정하지 않았다.

## 수동 재현 방법

`README.md`의 실행·테스트 순서를 따른다. 자동 검증 재현 시 Playwright와 Node.js가 필요하며 게임 실행 자체에는 필요하지 않다. 테스트는 전용 브라우저 컨텍스트를 사용하므로 사용자가 실제 브라우저에 저장한 순위 데이터를 변경하지 않는다.
