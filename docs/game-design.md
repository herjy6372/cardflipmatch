# 게임 기획서

## 1. 게임 개요

- 게임 제목: 두근두근 카드 뒤집기 (Card Flip Match)
- 장르: 싱글 플레이 캐주얼 / 기억력 퍼즐
- 플레이 대상: 클릭과 터치로 간단한 퍼즐을 즐기고 싶은 PC·모바일 사용자
- 실행 환경: PC 및 모바일 웹 브라우저
- 한 줄 콘셉트: 카드의 위치를 기억하고 제한 시간 안에 모든 짝을 찾아 50라운드에 도전하는 메모리 게임.

## 2. 제작 목적

- 플레이어가 느끼게 할 핵심 재미: 기억한 위치에서 같은 그림을 찾는 성취감과 시간이 줄어드는 긴장감.
- 게임을 통해 제공할 경험: 쉬운 2×2 카드 판으로 규칙을 익히고, 카드 수와 시간 조건이 달라지는 라운드를 통해 기억력과 집중력에 도전한다.

## 3. 게임 진행 순서

1. 사용자가 시작 화면에서 별명·나이·성별을 입력·선택한다. 나이·성별에는 ‘선택 안 함’도 제공한다. 성별과 별도로 남자 또는 여자 캐릭터를 자유롭게 선택하고 시작 버튼을 누른다. 캐릭터가 인사하고 배경음 재생을 요청한다.
2. 현재 라운드에 필요한 카드 짝을 생성하고 섞어 뒷면으로 배치한다. 카드 판이 준비되면 제한 시간을 시작한다.
3. 두 장씩 카드를 뒤집는다. 같은 그림이면 열린 상태로 유지하고, 다르면 두 번째 선택 후 0.5초 뒤 다시 덮는다. 모든 짝을 찾거나 시간이 끝날 때까지 반복한다.
4. 1~49라운드 성공이면 ‘N라운드 완료!’ 안내만 표시한다. 점수판·순위를 열거나 기록을 저장하지 않는다. 다음 라운드 버튼으로 누적 점수를 유지하며 진행한다.
5. 제한 시간 초과, 50라운드 전체 완료, 사용자의 ‘포기’ 중 하나가 발생하면 게임을 종료한다. 모든 라운드의 점수·보너스와 마지막 미완료 라운드의 짝 점수를 합산한 최종 점수판을 공개하고 기록을 한 번 저장한다.
6. ‘최종 총점 순위 보기’로 로컬 게임 전체 기록의 순위를 확인한다. ‘1라운드부터 새 게임’은 누적 0점부터 다시 시작한다. ‘결과 다시 보기’와 ‘처음으로’도 제공한다.

## 4. 게임 규칙

- 조작 방법: 마우스 클릭 또는 화면 터치로 카드 두 장을 선택한다. 키보드 Tab으로 이동하고 Enter/Space로 선택할 수도 있다. 이미 열린 카드와 찾은 카드는 다시 선택할 수 없으며, 두 장 판정 중에는 추가 선택을 막는다.
- 점수 획득 조건: 같은 짝을 찾으면 100점. 라운드 성공 시 남은 시간을 초 단위로 내림한 값 × 10점을 보너스로 받는다. 유효한 두 번째 카드 선택마다 시도 횟수를 1회 늘린다.
- 누적 점수: 다음 라운드에서도 점수를 유지한다. 성공 라운드의 보너스를 포함하고 시간 초과·포기 라운드에는 새 시간 보너스를 주지 않는다. 오답 감점은 없으며 마지막 라운드의 부분 짝 점수도 총점에 포함한다. 새 게임에서만 누적값을 초기화한다.
- 시도·시간: HUD 시도는 현재 라운드 기준이며 최종 결과는 게임 전체 합계다. 총 플레이 시간은 각 라운드의 실제 진행 시간 합계로, 완료 안내 화면의 대기 시간을 제외한다.
- 제한시간: 아래 확정 난이도 표와 계산식을 적용한다. PLAYING에서는 다른 탭으로 이동해도 시간은 계속 흐른다. 라운드 완료 안내 중에는 다음 라운드 시작까지 타이머를 멈춘다.
- 게임 종료 조건: (1) 제한 시간 내 해당 라운드의 모든 짝을 찾지 못함, (2) 50라운드 전체 완료, (3) ‘포기’ 버튼 선택. 세 경우에만 최종 점수판과 순위를 제공한다. 1~49라운드 성공은 게임 종료가 아니다.
- 포기는 플레이 중과 라운드 완료 안내 화면에서 가능하다. 안내 화면에서 포기해도 해당 라운드를 중복 합산하지 않는다. 종료 이후 새 도전은 항상 1라운드·0점부터 시작한다.
- 승리 또는 목표 달성 조건: 제한 시간 안에 현재 카드 수 ÷ 2쌍을 모두 찾으면 라운드 성공이다. 50라운드 성공이 최종 목표이며, 51라운드는 없다. 두 번째 카드를 선택하는 순간 시간이 0 이하이면 실패, 시간이 남아 있고 마지막 짝이 맞으면 성공으로 한 번만 확정한다.

### 확정 라운드별 난이도

기존 권장안을 최종 채택한 설정이며 원안을 대체한다. 기본 배열은 행×열이다.

| 라운드 | 기본 배열 | 카드 수 | 짝 수 | 구간 시작 제한 시간 | 구간 내 라운드당 감소 |
| --- | --- | ---: | ---: | ---: | ---: |
| 1 | 2×2 | 4 | 2 | 30초 | 0초 |
| 2~4 | 4×4 | 16 | 8 | 30초 | 1초 |
| 5~9 | 4×5 | 20 | 10 | 40초 | 1초 |
| 10~19 | 4×6 | 24 | 12 | 50초 | 1초 |
| 20~29 | 5×6 | 30 | 15 | 60초 | 1초 |
| 30~39 | 6×6 | 36 | 18 | 75초 | 1초 |
| 40~50 | 6×8 | 48 | 24 | 90초 | 1초 |

제한 시간 = 구간 시작 제한 시간 − (현재 라운드 − 구간 시작 라운드) × 감소량. 예를 들어 4라운드는 28초, 19라운드는 41초, 50라운드는 80초다. 모바일에서는 카드 수와 순서를 유지하고 열 수만 조정한다.

## 5. 화면 구성

### 시작 화면

- 게임 제목과 한 줄 설명
- 제한 시간 내 모든 짝 찾기 규칙과 클릭·터치 조작 안내
- 남자·여자 2D 캐릭터 선택과 미리보기, 시작 버튼
- 별명 1~12자, 나이 1~120세·선택 안 함, 성별 남성·여성·기타·선택 안 함. 나이·성별은 기록에 저장하지 않고 난이도에도 사용하지 않는다는 안내
- 배경음 음소거·볼륨 조절
- 게임 상태: READY

### 플레이 화면

- 현재 라운드/50, 남은 시간, 남은 쌍, 누적 점수, 현재 라운드 시도 횟수
- 앞면 이모지와 공통 뒷면으로 구성된 카드 그리드 및 뒤집기 애니메이션
- 포기 버튼, 배경음 음소거·볼륨 및 선택 효과음의 별도 음소거·볼륨
- 선택 캐릭터의 대기·짝 일치 응원·불일치 격려 애니메이션. PC는 카드 판 옆, 모바일은 상태 정보 위 작은 별도 영역에 배치
- 게임 상태: PLAYING. 두 카드 판정 중에는 카드 입력 잠금
- PC에서는 중앙 정렬된 카드 판, 모바일에서는 최대 4열 배치와 필요 시 세로 스크롤 제공. 2×2 라운드는 2열 유지

### 라운드 완료 안내 화면

- 게임 상태: ROUND_CLEAR. 1~49라운드 성공 때만 표시한다.
- ‘N라운드 완료!’와 다음 라운드 시작 버튼, 포기 버튼을 제공한다.
- 캐릭터는 축하하고 배경음은 이어 재생한다. 점수판·순위는 표시하지 않으며 종료 기록도 저장하지 않는다.
- 라운드 점수는 내부적으로 누적되고 다음 라운드로 이어진다. 안내 대기 중에는 시간을 차감하지 않는다.

### 게임 종료 화면

- 시간 초과, 50라운드 전체 완료 또는 사용자 포기 메시지
- 선택 캐릭터의 성공 축하 또는 실패 격려 동작과 결과 포즈
- 누적 총점·누적 보너스·총 플레이 시간·총 시도·총 찾은 쌍·완료 라운드 수·도달 라운드
- 최종 총점 순위 보기 버튼; 이어지는 순위 화면에 1라운드부터 새 게임 버튼 제공
- 처음으로 버튼
- 게임 상태: GAME_OVER. 종료 후 카드 입력을 막고 결과 수치를 고정

### 순위 화면

- GAME_OVER 안의 별도 화면으로 구성하며 결과 다음에 표시한다.
- 같은 난이도·점수 버전의 게임 전체 기록을 라운드 구분 없이 비교한다. 최근 500개 종료 게임을 보관하며 동일 별명의 여러 게임도 각각 표시한다. 이전 라운드별 순위는 섞지 않는다.
- 누적 총점 높은 순, 완료 라운드 많은 순, 총 플레이 시간 짧은 순, 총 시도 적은 순으로 정렬한다. 모두 같으면 공동 순위(1, 1, 3)를 사용한다.
- 순위·별명·전체 완료/시간 초과/포기·완료 라운드·총점·총 시간·총 시도를 표시하고 이번 기록을 강조한다. 나이·성별은 표시하지 않는다.
- 이 브라우저의 순위라는 범위를 명시한다. 저장 불가 시 이번 실행의 메모리 순위와 안내를 제공한다.
- 1라운드부터 새 게임, 결과 다시 보기, 처음으로를 제공한다. 순위 재방문은 기록을 추가하지 않는다.

## 7. 추가 기능

배경음과 사용자 캐릭터, 시작 전 정보 입력, 종료 후 로컬 순위는 확정 구현 범위다. 순위 저장은 필수로 변경되었으며 개별 최고 기록 요약과 테마는 선택이다. 선택 효과음은 기존 파일로 이번 구현에 포함한다.

- [x] 3분 배경음 연결, 반복 재생 및 개별 음소거·볼륨 — 확정 추가; 청감 검증은 test-checklist.md 참고
- [x] 남자·여자 2D 캐릭터 선택과 대기·인사·응원·격려·성공·실패 애니메이션 — 확정 추가

- [ ] localStorage에 같은 난이도 버전·라운드의 최단 성공 시간, 최고 점수, 최소 시도 횟수 저장
- [x] 카드 오픈·일치·불일치·성공·실패 효과음과 음소거 설정
- [ ] 동물·과일 등 이모지 테마 선택과 간단한 성공 축하 효과

저장이나 사운드 재생에 실패해도 기본 플레이를 유지한다. 캐릭터 선택과 배경음·효과음 각각의 볼륨·음소거 설정도 저장한다. 나이·성별은 현재 실행 메모리에서만 사용하고 저장·전송하지 않는다. 별명은 순위 기록에 저장하되 폼에는 자동 복원하지 않는다. 음악 재생 위치와 진행 중인 판은 저장하지 않고 새로고침 시 시작 화면으로 돌아간다.

## 8. 필요한 리소스

### 이미지

- 서로 구별하기 쉬운 카드 앞면 이모지 24종 이상. 한 판에서는 필요한 종류를 선택해 각각 두 장씩 사용
- CSS로 제작하는 카드 뒷면 패턴, 배경, 버튼
- 선택 리소스인 로고·일러스트는 images/에 보관
- PC·모바일 운영체제별 이모지 모양과 식별 가능성 확인

### 사용자 캐릭터 애니메이션

- 남자·여자 각 1종. 플레이어 정보의 성별과 별도로 자유롭게 선택하며 게임 능력과 규칙은 동일
- 현대적이고 상큼발랄한 제작 방향: 2~3등신, 둥근 실루엣, 또렷한 표정, 깔끔한 선, 민트·코랄·레몬 포인트와 캐주얼 의상
- 기본 미리보기는 남자 캐릭터이며 READY에서 변경 가능. 라운드 이동·새 게임·처음으로에서 선택 유지
- 캐릭터별 대기(2~3초 반복), 인사(0.8초), 일치 응원(0.6초), 불일치 격려(0.5초), 성공(1.2초), 실패(1초)의 6종 동작
- 투명 배경 PNG 대기 시트와 5종 반응을 묶은 4열×5행 시트, 별도 정적 대체 시트를 images/characters/male/ 및 female/에 보관한다. 움직임 감소 시 해당 행의 정적 프레임을 표시한다.
- 성공·실패 후 결과 포즈 유지. 연출은 카드 판정이나 타이머를 지연하지 않으며 카드 영역을 가리지 않음
- 움직임 감소 설정에서는 상태별 정적 포즈, 이미지 로딩 실패 시 대체 이미지 또는 이름 표시

### 배경음

- 3분(180초, 인코딩 오차 ±1초) 상큼발랄한 보컬 없는 음악 1곡: sounds/bgm/background.mp3
- 제작 방향: 약 120~130 BPM의 밝은 신스·플럭·벨과 가벼운 드럼, 자연스러운 반복 연결
- 시작 버튼 조작 후 재생하고 플레이·라운드 완료 안내·다음 라운드·최종 결과·순위에서 이어서 반복. 음악 길이는 라운드 제한 시간과 별개
- 처음으로 이동 시 정지·위치 초기화, 종료 후 새 게임은 처음부터 재생
- 숨겨진 탭에서는 음악만 일시정지하고 게임 시간은 유지. 복귀 시 시간 확인 후 재생 요청, 차단 시 수동 재생 버튼 제공
- 기본 배경음 30%, 효과음 70%. 각각 0~100% 볼륨 및 별도 음소거 제공, 재시작 시 음악 중복 재생 방지
- 직접 제작하거나 사용 허가가 확인된 로컬 음원을 제공하며 외부 스트리밍 API를 요구하지 않음

### 효과음

- 선택 기능: 카드 오픈(flip.mp3), 짝 일치(match.mp3), 불일치(mismatch.mp3), 라운드·전체 성공(success.mp3), 시간 초과·포기(fail.mp3)
- sounds/에 로컬 파일로 보관하고 직접 제작하거나 사용 허가가 확인된 음원 사용
- 첫 사용자 조작 이후 재생을 활성화하고, 음소거 제공

## 9. 프로젝트 완료 기준

아래는 실제 기기·청취 확인까지 포함한 최종 인수 기준이다. 구현 및 자동 검증이 완료된 항목과 남은 수동 확인은 test-checklist.md에 구분해서 기록한다.

- [ ] 게임이 브라우저에서 실행된다.
- [ ] 시작부터 종료까지 한 번의 플레이가 가능하다.
- [ ] 점수와 게임 규칙이 기획 내용과 일치한다.
- [ ] 다시 하기가 정상적으로 작동한다.
- [ ] PC와 모바일 화면에서 주요 요소를 사용할 수 있다.
- [ ] 확정 난이도 표와 시간 계산식이 1~50라운드에 적용되며 최대 48장·24쌍을 사용한다.
- [ ] 모든 난이도 변경 지점과 50라운드 완료를 확인하고, 51라운드로 진입하지 않는다.
- [ ] 중복 선택, 연속 입력, 시간 초과와 마지막 짝 판정이 겹쳐도 결과가 한 번만 결정된다.
- [ ] 재시작 후 이전 판의 타이머와 뒤집기 예약이 새 판에 영향을 주지 않는다.
- [ ] 화면 너비 320px 이상에서 가로 넘침 없이 조작할 수 있고, 모바일 최대 카드 수에서도 카드가 구분된다.
- [ ] HTML/CSS/JavaScript와 로컬 자산으로 핵심 기능을 실행하며 로그인·서버·외부 API·별도 기기 권한이 필요하지 않다.
- [ ] 3분 배경음의 길이·반복 연결·개별 볼륨·음소거와 라운드 간 이어 재생을 확인하고 중복 재생이 없다.
- [ ] 남자·여자 캐릭터 선택과 6종 동작이 정상 작동하며 PC·모바일에서 카드 조작을 방해하지 않는다.
- [ ] 움직임 감소·캐릭터 로딩 실패·배경음 재생 차단 시에도 기본 플레이가 가능하다.
- [ ] 선택 기능을 구현했다면 기록 저장 및 효과음 실패 상황에서도 게임이 계속 진행된다.
- [ ] 별명·나이·성별 입력과 캐릭터 선택이 독립적으로 동작하며 나이·성별이 저장되지 않는다.
- [ ] 게임 종료 후에만 누적 총점 순위·공동 순위·이번 기록·새 게임 버튼을 표시한다.
- [ ] 1~49라운드 성공 시 완료 안내만 표시하며 총점을 중복 합산하거나 기록을 조기 저장하지 않는다.

세부 개발 구조와 예외 처리 기준은 game-plan.md를 따른다. 체크 항목은 실제 구현과 검증 후 완료 표시한다.
