# 게임 리소스 명세서

대상: **두근두근 카드 뒤집기 (Card Flip Match)**  
갱신일: 2026-09-12  
기준: [game-plan.md](game-plan.md), [game-design.md](game-design.md) 및 게임 전체 누적 점수 / 시간 초과·50라운드 완료·포기 시에만 점수판 공개 요청

모든 경로는 프로젝트 루트 기준이다. 실제 구현에 맞춘 명세이며 테스트 결과는 [test-checklist.md](test-checklist.md)를 참고한다.

## 1. 공통 스타일

- **표현 방식:** 크림색 바탕과 민트·그린 포인트의 밝은 캐주얼 2D. 카드 앞면은 운영체제 기본 이모지, 뒷면·배경·버튼·순위 강조는 CSS다. 캐릭터는 기존 2~3등신의 둥근 실루엣·갈색 머리·캐주얼 의상을 유지한다.
- **주요 색상:** 화면 바탕 `#F8F6EF`, 본문 `#233E35`, 주요 버튼·카드 뒷면 `#175B4D`, 민트 `#73DCC5`, 코랄 `#FF8F87`, 레몬 `#FFE58A`. 민트·코랄 의상과 크림색 반바지를 기존 캐릭터 기준으로 유지한다.
- **외곽선:** 캐릭터의 깔끔한 짙은 외곽선과 UI의 둥근 모서리·얇은 테두리. 일치 카드는 테두리와 체크, 선택 캐릭터는 체크와 테두리, 초점은 외곽선으로 표시한다.
- **이미지 내 글자:** 이미지에 별명·나이·성별·순위·버튼 문구·워터마크를 넣지 않는다. 게임 제목·프로필 입력·결과·순위·말풍선은 HTML 텍스트로 표시한다. 사용자 별명은 HTML로 해석하지 않는다.

**파일 구성과 규격**

- 초기 명세의 동작별 PNG 10개와 정적 PNG 12개 제안은 위의 반응 시트 2개와 정적 시트 4개로 묶었다. 화면에서 사용하는 6종 동작과 상태별 정적 포즈는 유지한다. 기존 대기 PNG·idle.css·미리보기는 수정하지 않았다.
- 대기 원본: 각각 2172×724px, 4열×1행, 셀 543×724px, 3초 주기의 눈 깜빡임과 호흡.
- 반응 원본: 각각 971×1620px RGBA, 4열×5행, 열당 242.75px. 생성 결과의 실제 행 간격에 맞춰 `config.js`에 행 경계 좌표를 정의한다. 단순히 높이를 5등분하지 않아 인접 동작의 머리나 발이 노출되지 않게 한다.
- 남자 행 경계 Y: 0, 326, 638, 960, 1264, 1620. 여자 행 경계 Y: 0, 322, 646, 974, 1292, 1620. 각 행의 상단·높이에 맞춰 CSS 배경 크기와 위치를 계산한다.
- 정적 시트는 대응하는 대기·반응 시트를 별도 파일로 복사하여 제공한다. 단일 포즈만 담긴 잘라낸 PNG가 아니라, 애니메이션 없이 지정 프레임을 표시하는 대체 파일이다. 원본 URL 누락에 대응하지만 같은 이미지 자체의 디자인 결함을 교정하는 대안은 아니다.
- 제작 도구와 프롬프트는 [character-reactions.md](character-reactions.md)에 기록한다. 새 반응 이미지는 내장 image_gen으로 생성하고 배경 제거 편집을 거쳐 실제 투명 알파를 확인했다.

## 3. 사운드 리소스

| 파일 경로 | 역할 | 재생 시점 | 반복 |
| --- | --- | --- | --- |
| `sounds/bgm/background.mp3` | 기존 3분 배경음 | 시작 이후, 플레이·라운드 완료 안내·다음 라운드·최종 결과·순위 간 이어 재생 | 예 |
| `sounds/flip.mp3` | 카드 오픈 | 유효한 카드 선택 | 이벤트당 1회 |
| `sounds/match.mp3` | 짝 일치 | 마지막 짝을 제외한 일치 판정 | 판정당 1회 |
| `sounds/mismatch.mp3` | 불일치 | 두 번째 카드의 불일치 판정 직후 | 판정당 1회 |
| `sounds/success.mp3` | 라운드 성공·전체 완료 | 마지막 짝 판정과 성공 확정, 일치 효과음보다 우선 | 라운드 완료당 1회 |
| `sounds/fail.mp3` | 시간 초과·포기 | 게임 종료 확정 | 게임 종료당 1회 |

- 기존 음원은 수정하지 않았다. 배경음 요구 길이는 180초±1초, 기존 기록의 표시 길이는 약 180.43초다. 제작 방향은 무보컬·약 120~130 BPM의 밝은 신스·플럭·벨과 가벼운 드럼이다.
- 효과음은 직접 합성한 44.1kHz 모노 MP3, 128kbps다. 원본 길이는 오픈 0.16초, 일치 0.44초, 불일치 0.34초, 성공 1.12초, 실패 0.84초이며 MP3 패딩으로 표시 길이가 조금 다를 수 있다.
- `sounds/source/*.wav` 5개와 `sounds/generate_sfx.py`, `sounds/README.md`는 제작 자료다. 게임에는 MP3를 연결한다. 기존 `docs/sound-preview.html`은 그대로 유지한다.
- 배경음은 사용자 제공 음원이며 구체적인 출처·이용 허가 기록과 청감상 반복 연결 확인은 남아 있다. 효과음에는 외부 녹음·음악 샘플을 사용하지 않았다는 제작 기록이 있다.

## 4. 적용 규칙

- **로컬 실행:** `index.html`에서 상대 경로로 리소스를 연결한다. 외부 API·CDN·폰트·서버·빌드 도구 없이 실행한다. HTML은 화면, CSS는 반응형·표현, JavaScript는 상태·게임 규칙·오디오·순위를 담당한다.
- **플레이어 입력·순위 UI:** 별명 1~12자, 나이 1~120세 또는 선택 안 함, 성별 남성·여성·기타·선택 안 함을 HTML 폼으로 제공한다. 캐릭터 선택과 성별은 독립적이다. 순위에는 별명·종료 사유·완료 라운드·누적 총점·총 시간·총 시도를 표시한다. 새 이미지나 외부 서비스는 필요 없다.
- **완료 안내·포기:** 1~49라운드 성공에는 HTML 텍스트의 ‘N라운드 완료!’와 다음 라운드·포기 버튼만 표시한다. 점수판은 시간 초과·50라운드 전체 완료·포기에만 공개한다. 기존 성공 동작은 라운드 완료 안내에, 실패 격려 동작은 시간 초과·포기에 재사용한다.
- **누적 점수:** 모든 라운드의 짝 점수와 성공 보너스를 합산하고 마지막 미완료 라운드의 짝 점수도 포함한다. 시간 초과·포기에는 새 보너스가 없다. 완료 안내에서 포기해도 이미 확정한 점수를 다시 더하지 않는다. 새 게임은 1라운드·0점부터 시작한다.
- **저장:** `cardFlipMatch:v3`(스키마 3, 점수 버전 `run-total-v1`)에 최근 500개 종료 게임과 설정을 저장한다. 같은 난이도·점수 버전의 전체 게임 총점 → 완료 라운드 수 → 총 시간(ms) → 총 시도 순이며 동률은 공동 순위다. 이전 v2 라운드 기록은 보존하되 새 순위에서 제외하고 설정만 이어 쓴다. 나이·성별은 저장·전송하지 않는다. 1~49 성공과 순위 재방문은 기록을 추가하지 않는다.
- **배치·접근성:** PC는 캐릭터를 카드 판 옆, 모바일은 카드 판 위 별도 작은 영역에 표시한다. 모바일 최대 4열, 2×2는 2열이며 카드 수는 유지한다. 320px 이상, 카드·버튼 최소 44px, 간격 최소 8px을 목표로 한다. 많은 카드에서는 세로 스크롤과 상단에 붙는 상태 정보를 제공한다. 초점과 텍스트로 상태를 전달하고 닫힌 카드의 정답은 접근성 이름에 넣지 않는다.
- **애니메이션:** 결과 동작이 일반 반응보다 우선한다. 연출이 판정·타이머를 지연하지 않으며 이전 반응·판의 예약은 취소한다. 움직임 감소 시 포즈를 고정하지만 불일치 공개 시간 0.5초는 유지한다.
- **이미지 실패:** 동작 시트 → 해당 정적 시트 → 정적 대기 시트 → 캐릭터 이름 순서로 대체한다. 이미지 준비가 게임 시작을 막지 않는다.
- **오디오:** 첫 페이지 진입에는 자동 재생하지 않는다. 기본 배경음 30%, 효과음 70%, 각각 볼륨·음소거를 제공한다. 하나의 배경음 인스턴스를 사용하며 라운드 완료 안내·라운드 이동·결과·순위에서 이어 재생한다. 처음으로는 정지·0초 초기화, 종료 후 새 게임은 0초부터 재생한다.
- **탭·오류:** 숨겨진 탭에서는 음악만 멈추고 게임 시간은 유지한다. 복귀 시 시간부터 검사하고 이미 시작한 게임에서만 음악 재생을 요청한다. 차단 시 수동 재생 버튼, 저장 실패 시 세션 순위·안내를 제공한다.

## 5. 적용 상태

- **구현:** `index.html`, `css/style.css`, `js/config.js`, `game.js`, `character.js`, `audio.js`, `storage.js`를 생성하고 게임·입력·결과·순위 화면을 연결했다.
- **이미지:** 기존 대기 2개를 유지하고 반응 시트 2개·정적 대체 시트 4개를 추가했다. 6종 동작과 움직임 감소 표시를 연결했다. 기존 미리보기 파일과 대기 CSS는 변경하지 않았다.
- **사운드:** 기존 배경음·효과음 총 6개를 실제 이벤트에 연결했다. 음량·음소거·반복·탭 이동·재시작·재생 실패 대응을 구현했다.
- **플레이어·순위:** 시작 전 입력 검증, 나이·성별 비저장, 게임 종료 시에만 누적 총점 확정·전체 게임 순위·공동 순위·이번 기록 강조·저장 실패 대체를 구현했다. 라운드 완료 안내와 포기 버튼을 추가했고 기존 이미지·음원은 변경하지 않았다.
- **검증:** 자동 테스트와 화면 검토 결과 및 실제 기기·청취 확인이 남은 항목을 [test-checklist.md](test-checklist.md)에 구분하여 기록한다.
