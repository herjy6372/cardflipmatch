# 제작 전 파일 점검

점검일: 2026-09-12

## 결론

기본 게임 구현을 시작할 수 있는 기획서와 기본 자산은 준비되어 있다. 현재 파일 검사에서 손상된 이미지·오디오와 끊어진 미리보기 참조는 발견하지 못했다. 실제 게임 및 모든 캐릭터 동작이 완성된 상태는 아니다.

## 아직 제작할 파일과 기능

- 게임 진입 파일 index.html, css/style.css 및 js/config.js, game.js, character.js, audio.js
- 선택 기능인 기록 저장용 js/storage.js와 최종 실행 안내 README.md
- 캐릭터별 인사·응원·격려·성공·실패: 남자 5종, 여자 5종으로 총 10종. 현재는 두 캐릭터의 대기 애니메이션만 있음
- 캐릭터 정적 대체 이미지: 현재 CSS로 첫 프레임을 표시할 수 있지만, 스프라이트 로딩 실패에 대비한 별도 이미지 파일은 없음
- 카드 이모지 24종 이상을 config.js에 확정하고 카드 뒷면을 CSS로 구현. 별도 카드 이미지 파일은 필요하지 않음
- 실제 게임 이벤트에 오디오·애니메이션 연결, 1~50라운드 규칙, 타이머, 승패, 재도전 구현

## 실제 동작 확인이 남은 항목

브라우저 도구의 URL 보안 정책이 로컬 HTML 열기를 차단했다. 따라서 이번 점검은 파일 무결성·경로·문법 검사이며 실제 브라우저 동작 통과를 의미하지 않는다.

- [ ] character-preview.html을 브라우저에서 열어 남자·여자 선택, 눈 깜빡임, 호흡, 일시정지 및 정적 포즈 확인
- [ ] sound-preview.html에서 오디오 6개 청취 및 배경음과 효과음 음량 균형 확인
- [ ] 배경음 끝→처음 반복 연결에 끊김이나 긴 무음이 없는지 청취
- [ ] PC와 모바일에서 카드 크기에 맞춘 캐릭터 표시, 프레임 흔들림·가장자리 확인
- [ ] 움직임 감소 설정, 모바일 오디오 재생 제한 확인

원본 배경음과 기존 이미지·효과음은 수정하지 않았다. 실제 실행이 필요한 확인 항목은 게임 구현 후에도 다시 검증해야 한다.
