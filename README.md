# 두근두근 카드 뒤집기

HTML·CSS·JavaScript로 만든 PC·모바일용 싱글 플레이 메모리 게임입니다. 별명·나이·성별을 선택하고 캐릭터와 함께 50라운드에 도전합니다. **1~49라운드 완료 때는 완료 안내만**, **시간 초과·50라운드 전체 완료·포기 때는 누적 총점 점수판**을 표시합니다. 최종 결과의 **최종 총점 순위 보기**에서 이 브라우저의 게임 전체 기록을 비교할 수 있습니다.

## 실행

1. `CardFlipMatch/index.html`을 Chrome 또는 Edge에서 엽니다. 파일을 더블클릭해도 됩니다.
2. 별명 1~12자를 입력하고 나이·성별을 선택합니다. 나이·성별에는 ‘선택 안 함’이 있습니다.
3. 플레이어 성별과 관계없이 남자·여자 캐릭터를 고르고 **게임 시작**을 누릅니다.

게임 실행에는 설치·빌드·인터넷·서버·계정이 필요하지 않습니다. JavaScript는 켜져 있어야 합니다. 순위는 같은 브라우저·같은 파일 주소 또는 사이트 주소에 저장됩니다. 브라우저나 실행 주소를 바꾸면 기록이 다르게 보일 수 있습니다.

선택적으로 Python이 설치된 환경에서는 프로젝트 폴더에서 다음 명령으로 정적 서버를 실행할 수 있습니다.

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

이후 브라우저에서 `http://127.0.0.1:8765`에 접속합니다. 모바일 실제 기기에서 실행하려면 파일들을 정적 웹 호스팅에 올리거나 같은 네트워크의 별도 서버를 사용하세요. 로컬 PC의 127.0.0.1 주소는 다른 기기에서 접속할 수 없습니다.

## 조작과 규칙

- 마우스 클릭·화면 터치로 카드 두 장을 엽니다. 키보드는 Tab으로 이동하고 Enter 또는 Space로 선택합니다.
- 같은 그림이면 100점, 다르면 두 번째 선택 후 0.5초 뒤 닫힙니다. 그동안 추가 선택은 막습니다.
- 라운드 성공 시 남은 정수 초×10점을 추가합니다. 오답 감점은 없으며 점수는 다음 라운드에서도 계속 누적됩니다. HUD 시도는 현재 라운드 기준, 최종 시도는 게임 전체 합계입니다.
- 1라운드는 4장·30초, 최대 48장·24쌍입니다. 50라운드 성공은 전체 완료입니다.
- 1~49라운드 성공 시 ‘N라운드 완료!’ 안내에서 다음 라운드로 진행합니다. 이때 점수판·순위·기록 저장은 없습니다.
- 시간 초과·50라운드 전체 완료·포기 때만 게임을 종료하고 총점을 저장합니다. 마지막 미완료 라운드의 짝 점수도 포함하며 시간 초과·포기에는 새 보너스를 주지 않습니다.
- 플레이 중과 라운드 완료 안내에서 **포기**를 선택할 수 있습니다. 최종 결과 → 순위에서 **1라운드부터 새 게임**을 시작하면 누적값이 0으로 초기화됩니다. 종료 후 **처음으로**는 시작 화면으로 돌아갑니다.
- 최종 총 플레이 시간은 라운드 진행 시간 합계로, 완료 안내 화면에서 기다린 시간은 제외합니다. 새로고침·페이지 이탈 시 진행 중인 게임은 저장·복원하지 않습니다.
- 다른 탭으로 이동해도 게임 시간은 계속 흐릅니다. 배경음만 일시정지하며 복귀 시 남은 시간을 재검사합니다.
- 배경음·효과음은 각각 볼륨·음소거를 조절할 수 있습니다. 재생이 차단되면 **배경음 재생** 버튼을 누릅니다.

## 순위와 저장 범위

순위는 **같은 난이도·점수 버전의 게임 전체 기록**끼리 라운드 구분 없이 비교합니다. 정렬은 높은 누적 총점 → 많은 완료 라운드 → 짧은 총 플레이 시간(ms) → 적은 총 시도입니다. 모두 같으면 공동 순위(1, 1, 3)를 사용합니다. 같은 별명의 여러 게임도 각각 기록하며 최근 500개 종료 게임을 보관합니다. 현재 기록은 강조됩니다.

`localStorage`의 `cardFlipMatch:v3`에 별명과 게임 전체 기록, 캐릭터·오디오 설정만 저장합니다. 이전 v2의 라운드별 기록은 삭제하지 않지만 새 순위에 섞지 않습니다. v3 데이터가 없으면 v2 설정만 이어 사용합니다. 나이·성별은 저장·전송하지 않습니다. 입력 폼과 진행 중인 게임은 새로고침 후 복원하지 않습니다. 저장이 막히거나 손상되어도 이번 실행의 메모리 순위로 계속할 수 있습니다.

이번 누적 점수 수정 파일: `index.html`, `css/style.css`, `js/game.js`, `js/storage.js`, `js/config.js`, 세 기획·리소스 문서, `README.md`, `docs/test-checklist.md`, 두 자동 테스트. CSS는 모바일 누적 총점 표시를 보정했습니다. 기존 캐릭터·오디오 모듈과 이미지·음원은 변경하지 않았습니다.

## 테스트

간단한 직접 테스트는 다음과 같습니다.

1. 빈 별명으로 시작이 막히는지 확인한 뒤 정보를 입력하고 1라운드를 시작합니다.
2. 서로 다른 카드를 열면 0.5초 후 닫히고, 같은 카드를 연속 선택해도 시도가 늘지 않는지 확인합니다.
3. 1라운드의 모든 짝을 맞추면 점수판 없이 ‘1라운드 완료!’가 표시되는지, 다음 라운드에서도 누적 점수가 유지되는지 확인합니다.
4. 시간 초과 또는 포기를 실행하면 이전 라운드 점수와 현재 짝 점수를 합한 최종 점수판 → 총점 순위가 표시되는지 확인합니다. 새 게임은 1라운드·0점이어야 합니다.
5. 창 너비를 320·375·768·1280px로 변경하고 캐릭터·카드·순위가 겹치지 않는지 확인합니다.
6. 음량·음소거를 바꾸고 탭 이동·처음으로·새로고침을 확인합니다. 운영체제의 움직임 감소 설정에서도 플레이해 봅니다.

자동 테스트는 **게임 실행과 별개**로 Node.js와 Playwright가 필요합니다. Playwright가 이미 있는 환경에서 실행하거나 테스트 도구를 설치합니다.

```powershell
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/game.test.cjs
node tests/media.test.cjs
```

설치된 Chrome을 사용할 경우 Playwright 브라우저 다운로드 대신 다음 환경변수를 지정할 수 있습니다.

```powershell
$env:GAME_TEST_BROWSER = 'C:/Program Files/Google/Chrome/Application/chrome.exe'
node tests/game.test.cjs
node tests/media.test.cjs
```

`game.test.cjs`는 기본적으로 로컬 파일을 열고, `media.test.cjs`는 임시 로컬 HTTP 서버를 열어 전체 게임 테스트와 미디어 검증을 수행한 뒤 서버를 닫습니다. 스크린샷과 JSON 결과는 `.tools/test-results/`에 저장됩니다. 실제 수행 결과와 남은 기기·청취 확인은 `docs/test-checklist.md`에 기록했습니다.
